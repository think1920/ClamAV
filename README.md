# 🚀 Remote PC Control via Gmail

## 📌 Giới thiệu
Đây là đồ án thực hành môn **Mạng Máy Tính** tại Trường Đại học Khoa học Tự nhiên – ĐHQG HCM.  
Đề tài: **Điều khiển máy tính từ xa bằng Gmail**.  

Ứng dụng cho phép người dùng điều khiển một máy tính khác thông qua địa chỉ IP hoặc Gmail với nhiều tính năng quản lý hệ thống (process, app, file, màn hình, webcam…).

## ⚙️ Cài đặt môi trường
Clone repo về máy:
   ```bash
   git clone https://github.com/think1920/EmailRemoteControl.git
   ```

## 🖥️ Giao diện người dùng (UI)
Ứng dụng hỗ trợ 2 chế độ điều khiển:
- **Qua địa chỉ IP**
- **Qua Gmail** (yêu cầu thêm Gmail để xác thực)

Giao diện gồm các chức năng chính:
- List Process/App đang chạy
- Start/Stop ứng dụng
- Chụp màn hình hoặc Webcam
- Keylogger (ghi lại phím nhấn)
- Truyền file (Upload/Download)
- Lấy địa chỉ MAC
- Liệt kê cây thư mục
- Restart/Shutdown máy

## 📂 Các lệnh hỗ trợ
- `List Processes` – Liệt kê tiến trình đang chạy  
- `List Apps` – Liệt kê ứng dụng đang chạy  
- `Start App` – Khởi chạy ứng dụng  
- `Stop App/Process` – Dừng ứng dụng hoặc tiến trình  
- `Screenshot/Webcam` – Chụp ảnh màn hình hoặc webcam  
- `Keylogger` – Bắt phím nhấn  
- `File Transfer` – Gửi/nhận file giữa client và server  
- `MAC Address` – Xem địa chỉ MAC  
- `Directory Tree` – Liệt kê thư mục  
- `Shutdown/Restart` – Tắt hoặc khởi động lại máy
